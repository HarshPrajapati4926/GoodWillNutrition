# Good Will Nutrition and Wellness Centre

A modern, responsive website for Good Will Nutrition and Wellness Centre (Azamgarh) built with Next.js, TypeScript, and Tailwind CSS.

## Features

- Home, About, Services, Contact, and Diet Tips (blog) pages
- Reusable components: Navbar, Footer, HeroSection, ServiceCard, TestimonialCard, ContactForm
- Floating WhatsApp button and WhatsApp-based contact form
- SEO metadata, sitemap, and robots.txt targeting local nutrition-related keywords
- Fully responsive, green/white/red theme inspired by the brand logo

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

## Configuration

Update business details (phone, WhatsApp number, email, address, Google Maps link) in [`src/lib/data.ts`](src/lib/data.ts) before deploying.

## Build

```bash
npm run build
npm run start
```
